# Horno Tuanis - Actualizaciones

[**Descargar el asistente de actualización para Windows**](https://github.com/Jesulin123/horno-tuanis-descargas/releases/latest/download/HornoTuanis_Actualizar.exe)

1. Cierre Horno Tuanis.
2. Abra el asistente descargado y pulse **Elegir aplicación instalada**.
3. Seleccione **HornoTuanis_Etiquetas.exe** en la carpeta donde utiliza habitualmente la aplicación.
4. Pulse **Actualizar ahora**. La aplicación se abrirá al terminar.

A partir de esta versión también puede usar **Buscar actualizaciones** dentro de la aplicación.

La actualización conserva sus productos, credenciales, configuración, historial y etiquetas guardadas.
El asistente requiere una instalación existente. Este repositorio contiene exclusivamente descargas e información de versiones.
